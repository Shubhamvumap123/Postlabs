
## 2026-11-05 - Dashboard Forms and Action Buttons Accessibility
**Learning:** In the Dashboard component, form inputs lacked explicit 'htmlFor' and 'id' associations, relying instead on wrapping elements or implicit associations which can fail for screen readers. Furthermore, action buttons (Edit, Delete) in the job list relied entirely on visual context and icon presence without 'aria-label' descriptions that incorporate the specific job context, and lacked visual focus indicators for keyboard users.
**Action:** Always ensure explicit programmatic label associations by using the 'htmlFor' attribute on the '<label>' and a matching 'id' attribute on the corresponding input. When adding accessibility attributes to item-specific action buttons in a list, always include the specific item's title or identifier in the label (e.g., 'aria-label="Edit job: ${job.company}"') to provide clear context for screen readers, and add explicit 'focus-visible' styles to ensure keyboard navigation visibility.
